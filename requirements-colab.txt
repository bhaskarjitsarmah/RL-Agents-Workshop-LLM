# COLAB / GPU training stack.
#
# Read this before changing a pin: unpinned installs are the single most common
# cause of a dead workshop. Colab's preinstalled torch moves without warning,
# Unsloth replaces torch during install (forcing a runtime restart), and TRL's
# GRPOConfig field names have churned repeatedly across minor versions.
#
# Target hardware: Google Colab free T4 -- Turing (sm_75), 16GB, fp16 ONLY.
#   * no bfloat16          -> every config uses fp16=True, bf16=False
#   * no FlashAttention-2  -> attn_implementation="sdpa"
#   * vLLM is unreliable   -> use_vllm=False / fast_inference=False by default
#
# VERIFY BEFORE THE WORKSHOP (see scripts/check_api_surface.py):
#   python scripts/check_api_surface.py
# It prints the actual dataclass fields of SFTConfig/GRPOConfig for the resolved
# versions. Correct trainers.py against THAT, not against documentation.

-r requirements.txt
